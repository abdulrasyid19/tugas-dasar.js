1. Mulai

2. Masukkan nilai tugas

3. Masukkan nilai UTS

4. Masukkan nilai UAS

nilai akhir = (0.3 * tugas) + (0.3 * UTS) + (0.4 * UAS)

- Selain itu → Grade = E

7. Tampilkan Nilai Akhir

8. Tampilkan Grade

9. Selesai -->

    grade = "E";

console.log("Grade:", grade); -->
